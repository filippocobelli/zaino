# Firmware Zaino

```bash
./build.sh http://IP-DEL-SERVER:3021
```

Produce `zaino-firmware.bin`, da installare all'indirizzo `0x0` con il firmware updater ZECTRIX mantenendo le impostazioni. Guida completa: [../docs/installazione.md](../docs/installazione.md). Dettagli tecnici: [../docs/firmware.md](../docs/firmware.md).
